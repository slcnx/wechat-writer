# 找图 skill

脚本都在本 skill 的 `scripts/` 下（绝对路径 = CODEX_HOME/skills/image-sources/scripts），用环境变量 `WX_WRITER_NODE` 指向的 node 运行（没有就用 `node`），工作目录就是文章目录（`--dir .`）。每个脚本最后输出一段 JSON，`ok:false` 时看 `error`。

## A. 小红书取图（浏览器需已登录小红书）

1. 每个需要配图的小节，想 1–2 个**具体**关键词（菜名 + 地名最好，如「荥经砂锅雅鱼」「乐山跷脚牛肉」），不要用泛词。
2. 搜索：`node xhs.mjs search --q 荥经砂锅雅鱼 --n 12` → 返回笔记列表 `{note, title, author, likes}`（已排除视频笔记）。
3. 按标题挑与本节内容**最贴合**的 1–2 篇（实拍菜品/地方实景优先；跳过广告、探店打卡合集、人像自拍、带大段文字的封面图）。
4. 下载：`node xhs.mjs fetch --note <note 链接> --max 2` → 图片已存进 `materials/images/` 并登记为新的 `图N`，返回 `credit`（如「小红书@张三」）。
5. 若 `login:true`：说明小红书登录过期，**不要反复重试**；本轮先不配这些图，在回复里提醒用户"请在应用打开的浏览器里扫码登录小红书"。
6. 脚本拿不到图（页面结构变化等）时，可用 browser 工具（Playwright MCP）打开搜索页自行查看，但下载仍优先用脚本。

**署名（必须）**：小红书来的图，图注末尾写「图｜小红书@作者」（作者取 `images.json` 里该图的 `credit`）。不要写成「网络图片」，不要省略署名。

**选图要求**：画面与段落内容一致（写砂锅雅鱼就配砂锅雅鱼，不拿山景冒充）；同一篇里避免同一作者超过 3 张；画面里有可辨认的人脸、他人店招大字、二维码/水印很重的不用。

## B. 生图（插画、示意地图）

`node gen-image.mjs --prompt "画面描述" --size 16:9 --note 用途`

- 未配置生图接口时会返回错误，此时跳过并在回复里说明。
- 适合：概念插画、氛围图、地图类信息图。**不适合**冒充具体菜品或门店实拍。
- **涉及中国地图**：必须是完整的标准中国地图（含台湾、海南、南海诸岛），不画国界细节的写意风格也要保证轮廓完整；生成后自己检查不了画面时，在回复里提醒用户核对地图完整性。
- 图注照常写画面说明，结尾写「图｜AI 生成」。

## 登记规则

两个脚本都会把图片追加到 `materials/images.json`（`{id, src, from, credit}`）。正文引用写 `src="images/imgNN.ext"`，并把 id 写进 `out/meta.json` 的 `images`。不要手改已有编号。
