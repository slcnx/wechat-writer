# 开发与部署

## 架构

```
公众号写作助手（Node 本地网页，只监听 127.0.0.1:8848）
 ├─ 内置 Codex CLI（@openai/codex，独立 CODEX_HOME）──HTTPS──▶ DeepSeek / 任意 Responses API
 │    └─ 内置 skills：wechat-article / wechat-publish
 └─ playwright-core ──▶ 系统 Edge / Chrome（独立用户目录）──▶ mp.weixin.qq.com
```

| 目录 | 内容 |
|---|---|
| `src/server.js` | 本地 HTTP 服务 + API（校验 Host 防 DNS 重绑定、POST 只收 JSON 防 CSRF） |
| `src/config.js` | 设置读写；生成 `CODEX_HOME/config.toml`（Key 只经环境变量传入）；同步 skills |
| `src/codex.js` | 调用 `codex exec`（prompt 走 stdin，避免 Windows 转义问题） |
| `src/jobs.js` | 文章任务、素材落盘、成稿读取 |
| `src/article.js` | HTML 清洗、校验、手机预览页 |
| `src/publisher.js` | Playwright 操作公众号后台（登录、新建图文、富文本粘贴） |
| `skills/` | 内置 Codex skills，改写作规范只需改这里 |
| `scripts/build-dist.mjs` | 交叉构建六个平台的便携包 |
| `.github/workflows/build.yml` | CI：三端测试 → 打包 → 六平台原生冒烟 → tag 发布 Release |

Codex 生成的 `config.toml` 要点：`wire_api = "responses"`、`env_key = "WX_WRITER_API_KEY"`；
Windows 上额外写 `[windows] sandbox = "unelevated"`（默认沙箱需要管理员预配置，否则所有命令都被 `blocked by policy`）。

## 源码运行

```bash
npm ci
npm test          # 单元测试 + 真实浏览器富文本粘贴测试（无 Chrome/Edge 时自动跳过）
npm start         # 或 ./scripts/start.sh；Windows 用 scripts/start-win.cmd
```

Windows 一键源码安装（会用 winget 装 Node LTS、建桌面快捷方式）：

```powershell
powershell -ExecutionPolicy Bypass -File .\scripts\install-win.ps1 -BaseUrl https://api.deepseek.com
```

## 构建便携包

```bash
node scripts/build-dist.mjs                    # 全部 6 个平台
node scripts/build-dist.mjs win-arm64 mac-arm64 # 指定平台
NODE_MIRROR=https://registry.npmmirror.com/-/binary/node node scripts/build-dist.mjs   # 国内加速
```

原理：在任意一台机器上用 `npm ci --os=<目标> --cpu=<目标>` 装上目标平台的 Codex 二进制，再从 Node 官方下载目标平台的 `node` 可执行文件放进 `runtime/`，加启动脚本打包。每个包约 190~210 MB（Codex 二进制占大头）。

## 发布（GitHub Actions）

- push / PR：Ubuntu、Windows、macOS 三端跑测试，打出 6 个平台包作为 Artifact，并在各平台原生 runner（含 `windows-11-arm`、`ubuntu-24.04-arm`、`macos-15-intel`）上解压冒烟。
- 打 tag 发布：

```bash
git tag v0.1.0 && git push origin v0.1.0
```

工作流会自动创建 Release，附带 6 个包和 `SHA256SUMS.txt`。

## 自建网关（可选）

任何提供 OpenAI **Responses API**（`/v1/responses`）的地址都能用，例如局域网里的 CLIProxyAPI：设置里把 API 地址填成 `http://<网关IP>:8317/v1`，模型从「测试连接」列表里选。只支持 Chat Completions 的服务不能直接给 Codex 用（Codex 已不支持 `wire_api = "chat"`）。
